# Sources

All documents are public and are downloaded by `python src/fetch_docs.py` into `docs/raw/`
(gitignored, never committed). Date accessed for every source: 2026-10-07.

Rules must cite the file name and page. Record the edition shown here when a rule is authored.

|---|---|---|---|---|

## Known limits

- Toyota's Hilux Body Builder's Guide was dropped: the official link redirects to a Toyota Europe sign-in page, so it is not openly downloadable. The light domain therefore has regulatory sources only.
- Isuzu and Hino are not included: no official public body-builder document was verified.
- FUSO is the only manufacturer source, and its documents are short compliance tables.
- The Truck Loading Code URL sits under NZTA's consultation path; the document itself states it is the edition published 2026.
